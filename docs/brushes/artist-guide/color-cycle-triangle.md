# Color Cycle Triangle

**Preset:** `color-cycle-triangle`

**Role:** faceted animated contour and directional rhythm

**Layer requirement:** Color Cycle layer. This brush cannot draw on a normal layer.

Color Cycle Triangle is a Color Cycle stroke whose repeated triangular tip
makes direction and segmentation visible. The brush is selected through the CC
shape buttons rather than shown as a normal Brush Library tile.

## Controls

| Control | Effect and use |
| --- | --- |
| CC stamp buttons | Triangle is the active tip; other buttons can switch to Square, Checkered, Round, Diamond variants, Shape, or Gradient systems. |
| Size | Scale of each triangular unit and the resulting line weight. |
| Spacing / Vel | Interval between triangles and optional speed response. Higher spacing makes each facet legible. |
| Speed / Vel | Colour-cycle rate and optional link to drawing speed. |
| Bands | Number of indexed colours moving through the triangular sequence. |
| FG Grad / Man Grad / Sample | Chooses foreground-derived, authored, or canvas-sampled colour sources. |
| Foreground controls | Light, Hue, Sat, Opacity, and Stops define variation from the foreground colour. |
| Manual controls | Edit gradient stops, positions, opacity, and saved gradients. |
| Sample controls / Soft seam | Capture canvas colour and control the loop join. |
| Stamp Dither | Adds pixel texture inside each triangle. |
| Algorithm / Pattern | Chooses the internal dither distribution. |
| Res / Pres Res / Max | Controls dither cell size and pressure-linked maximum. |
| BG Fill | Makes dither gaps use background colour or reveal the painting below. |
| Pressure / Min / Max | Changes triangle and stroke size with pressure. |
| Rotation | Aligns or turns the triangular facets with the gesture. |
| Lostedge | Removes parts of the faceted edge. |
| Dashed / L / G / V | Organizes triangles into larger rhythmic groups. |

Its starting settings otherwise resemble Color Cycle Stroke: roughly Size 20,
Spacing 8, 30 FPS, and 12 bands.

## Painting with it

- Let the triangle point support a direction: growth, attack, flow, ascent, or
  fracture.
- Increase spacing enough to reveal the faceted identity. At very low spacing
  it can become an unnecessarily complicated ordinary line.
- Repeat the triangle rhythm on related edges, then interrupt it where the form
  or narrative changes.

## Starting points

- **Directional trim:** moderate spacing, stable rotation, sampled palette,
  slow cycle.
- **Warning signal:** few high-contrast bands, faster Speed, separated facets.
- **Crystalline seam:** Stamp Dither on, hard pixel cells, restrained Lostedge.

Avoid using the pointed rhythm on contours with no directional role. The tip is
strongest when its geometry explains something.
