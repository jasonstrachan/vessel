# Spam Text

**Preset:** `spam-text`

**Role:** language, data, noise, and voice as painted material

Spam Text turns words into repeated marks. Its content can be read, half-read,
or reduced to texture, but that level of legibility should be intentional.
Text brings cultural meaning immediately; it is never a neutral pattern.

## Controls

| Control | Effect and use |
| --- | --- |
| Content preset | Mixed Chaos, Classic Spam, Crypto Spam, Nigerian Prince, or Pharma Ads. Each carries a different cultural voice and history. |
| Custom text | Replaces preset language with authored content. Use when the actual words must belong to this work. |
| Font | Courier New, Consolas, Monaco, Lucida Console, Roboto Mono, Source Code Pro, Terminal, or Menlo. Font changes period, machine character, and legibility. |
| Size | Type scale from 8–72. Large text becomes statement; small text becomes texture or data. |
| Opacity | Strength and readability of the text. |
| Spacing / Vel | Distance between text stamps and optional response to drawing speed. |
| Lostedge | Omits or weakens parts of the textual trail. Useful for damaged transmission or fading memory. |
| Auto Pick | Samples canvas colour as the text is painted, embedding language in the image. |
| Pressure / Min / Max | Varies type scale with pressure. |
| Grid Snap / grid size | Aligns text to a shared module, useful for terminals, ledgers, architecture, and structured fields. |

The preset begins around Size 20, Spacing 10, full opacity, Grid Snap on, the
Courier font family, and Mixed Chaos content.

## Painting with it

- Decide whether the viewer should read the words. Large scale, regular spacing,
  contrast, and grid alignment improve legibility; small scale, overlap, and
  Lostedge turn language into residue.
- Prefer custom text when the work has a specific speaker. Preset spam is useful
  when mass solicitation, fraud, networks, or generic machine speech is itself
  the subject.
- Let placement create syntax. A trail, block, interruption, halo, or censoring
  band says something different even with identical words.

## Starting points

- **Readable declaration:** Custom text, large Size, high contrast, regular
  Spacing, Grid Snap on.
- **Data atmosphere:** small Size, low opacity, Auto Pick on, layered passes.
- **Broken transmission:** moderate Lostedge, variable pressure, irregular
  spacing.

Do not use words only because they make instant “complexity.” Read every visible
phrase as part of the artwork and take responsibility for its voice.
