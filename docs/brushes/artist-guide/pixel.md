# Pixel

**Preset:** `pixel-square`

**Role:** precise hard-edged construction

Pixel is Vessel's clearest brush. It is suited to decisions that should not be
ambiguous: a contour, a small correction, a graphic symbol, or one intentional
pixel. Its default square tip and un-antialiased edge make scale visible.

## Controls

| Control | Effect and use |
| --- | --- |
| Square / Round | Chooses the tip geometry. Square declares the pixel grid; Round softens the silhouette without becoming the Soft brush. |
| Size | Sets line weight. Use a small family of sizes to establish contour hierarchy. |
| Opacity | Controls how completely the mark replaces what is below. High opacity is decisive; low opacity builds transparent pixel strata. |
| Spacing / Vel | Sets stamp continuity and optionally links it to drawing speed. Increase spacing for beads, perforation, or visible rhythm. |
| Lostedge | Drops or weakens edge material. Useful where a contour should disappear into light or atmosphere. |
| Sprd | Spreads palette choices in supported dither behaviour. Keep low for colour unity; raise for chromatic grain. |
| Sample | Automatically picks colour from the canvas while drawing. Useful for repair and integration. |
| BG Fill | Fills dither gaps with background colour rather than revealing existing paint. |
| Dither controls | Algorithm, Res, Pres Res, Max, Pxl Edge, Smoosh, and Pattern options when dithering is enabled. See [Dither vocabulary](README.md#dither-vocabulary). |
| PigLift | Strength, Feather, and Texture subtract existing paint before the new mark. |
| Riso | Intensity, Hue Jitter, and Edges add print texture and imperfect colour registration. |
| Pressure / Min / Max | Varies size around the base size. A narrow range adds hand emphasis without losing the graphic system. |
| Rotation | Rotates the tip. Most visible with the square tip. |
| Dashed / L / G / V | Creates measured broken lines; velocity can expand the gaps. |
| Grid Snap / grid size | Locks marks to a common module for architecture, lettering, icons, and repeated motifs. |

## Painting with it

- Use the smallest size that still states the intended edge. Detail is stronger
  when it clarifies a form rather than merely occupying space.
- Let some contours remain open. Lost edges make the viewer complete the form
  and keep every boundary from receiving equal emphasis.
- Repeat a grid size, spacing, or dash metre elsewhere in the work so a local
  detail becomes part of the painting's language.

## Starting points

- **Primary contour:** high opacity, continuous spacing, pressure range kept
  modest, no Riso.
- **Fragile or distant edge:** smaller size, lower opacity, some Lostedge.
- **Constructed ornament:** square tip, Grid Snap on, deliberate high spacing or
  dashes.

Avoid solving a weak large shape with many tiny corrections. Zoom out and
repair the mass first.
